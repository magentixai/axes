# Minimum Viable Assurance Report Profile

> **Status: in development — Roadmap P2-P3.** This stub states intended scope so reviewers can challenge the plan before the text lands. Comments welcome via the issue templates.

The layered report structure every conformant evidence set must be able to support: Executive Summary; Board & Risk View; Authority & Delegation View; Execution Topology View; Security Expectation Lens; Control & Assurance Assertions; Evidence Quality & Completeness; Exceptions & Remediation; Technical Trace Appendix; Forensic Evidence Appendix; Standards Field Mapping Appendix. Worked instances of outputs A-D exist today in `examples/golden-trace/out/reports/`.
