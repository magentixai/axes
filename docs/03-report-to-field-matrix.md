# Report-to-Field Requirements Matrix

> **Status: in development — Roadmap P2-P3.** This stub states intended scope so reviewers can challenge the plan before the text lands. Comments welcome via the issue templates.

Maps every statement in the four target report outputs (A board / B audit / C regulator / D forensic, plus the insurer flavour) to the exact fields that support it. Rule: no report line without supporting fields; no field without report value. The Golden Trace reports are the first fully-resolved instances.
